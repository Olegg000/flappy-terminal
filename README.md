## Установка

Скопируй одну команду в терминал. Установщик найдёт Python, скачает игру и добавит
команду `flappy`.

**macOS и Linux** (Terminal, iTerm2, любой терминал Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/Olegg000/flappy-terminal/main/install.sh | sh
```

**Windows** (PowerShell, лучше всего в Windows Terminal):

```powershell
irm https://raw.githubusercontent.com/Olegg000/flappy-terminal/main/install.ps1 | iex
```

Потом просто:

```bash
flappy
```

На macOS и Linux команда появится в новом окне терминала. В Windows она работает
сразу, в том же окне PowerShell.

### Что делает установщик

| | macOS и Linux | Windows |
|---|---|---|
| Python | ищет Python 3.9+ с curses; если нет, подскажет, как поставить | ищет Python 3.9+; если нет, предложит поставить Python 3.13 через winget |
| Библиотеки | ничего не ставит, curses уже есть | ставит пакет `windows-curses` через pip |
| Игра | `~/.local/share/flappy-terminal/flappy.py` | `%LOCALAPPDATA%\flappy-terminal\flappy.py` |
| Команда | `~/.local/bin/flappy` | `%LOCALAPPDATA%\flappy-terminal\bin\flappy.cmd` |
| PATH | дописывает `~/.local/bin` в `.zshrc`, `.bashrc`, `.bash_profile`, конфиг fish или `.profile` | добавляет папку в PATH пользователя |

Права администратора и `sudo` не нужны, всё ставится в домашнюю папку.

### Обновление и удаление

Обновиться: запусти ту же команду установки ещё раз.

Удалить на macOS и Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/Olegg000/flappy-terminal/main/install.sh | sh -s -- --uninstall
```

Удалить на Windows:

```powershell
$env:FLAPPY_UNINSTALL=1; irm https://raw.githubusercontent.com/Olegg000/flappy-terminal/main/install.ps1 | iex
```

Рекорды остаются в `~/.flappy_term.json`, удали этот файл вручную, если нужно.

### Без установки

```bash
curl -fsSLO https://raw.githubusercontent.com/Olegg000/flappy-terminal/main/flappy.py
```

```bash
python3 flappy.py
```

На Windows перед этим нужен `py -m pip install windows-curses`.

## Управление

| Клавиша | Действие |
|---|---|
| Space, ↑, W, K | взмах и старт игры |
| ← / → | сложность на заставке: EASY, NORMAL, HARD |
| P | пауза |
| M | звук (системный бип), по умолчанию выключен |
| D | демо: игра играет сама |
| T | вернуться на заставку |
| Space или R | заново после проигрыша |
| Q, Esc, Ctrl-C | выход |

Если 12 секунд ничего не нажимать на заставке, включится демо. Любая клавиша взмаха
забирает управление у автопилота, и счёт начинается с нуля.

## Флаги

| Флаг | Что делает |
|---|---|
| `--easy`, `--hard` | пресет сложности: шире или уже просветы, медленнее или быстрее трубы |
| `--ascii` | только ASCII-графика; включается сам, если терминал не в UTF-8 |
| `--no-color` | монохромный режим |
| `--fps N` | частота кадров, по умолчанию 60; физика всегда 60 Гц |
| `--seed N` | одна и та же последовательность труб |
| `--demo` | сразу включить автопилот |
| `--selftest` | проверить игровую модель без терминала |

## Что внутри

- Физика с фиксированным шагом 60 Гц и дробными координатами, взмах срабатывает в том же кадре.
- Просветы постепенно сужаются, а скорость растёт, с потолком для каждой сложности.
- Птица машет крыльями и наклоняется по скорости; облака, горизонт и кусты двигаются с параллаксом.
- Смена дня и ночи каждые 10 очков, медали за 10, 20, 30 и 40 очков.
- Рекорд для каждой сложности сохраняется между запусками; битый файл рекордов просто игнорируется.
- Окно можно менять на ходу; если оно меньше 50×16, игра попросит его увеличить.

## Если что-то не так

- **Квадратики вместо графики.** Терминал или шрифт не умеет блочные символы.
  Запусти `flappy --ascii` или открой игру в Windows Terminal, iTerm2 или другом современном терминале.
- **`flappy: command not found` на macOS или Linux.** Открой новое окно терминала: PATH
  подхватывается при запуске оболочки.
- **Windows на ARM.** Для `windows-curses` нет сборки под ARM64; поставь x64-версию Python
  с python.org и запусти установщик снова.

## Тесты

`tests/smoke_test.py` запускает игру в псевдотерминале, нажимает клавиши, меняет размер окна,
меряет нагрузку на процессор и прогоняет вывод через маленький эмулятор VT100, чтобы видеть
настоящие кадры. Работает на macOS и Linux.

```bash
python3 tests/smoke_test.py flappy.py
```

```bash
python3 tests/smoke_test.py flappy.py --show --only play
```
